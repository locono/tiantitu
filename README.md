# 天梯图 · tiantitu.com.cn

一个纯静态的硬件性能天梯图网站，单文件 `index.html`，零外部依赖，打开即用。

## 这是什么

「天梯图」把市面上主流的电脑与手机硬件放在同一张榜单里，按综合性能从高到低排列，帮助你快速回答这些问题：

- 我的手机芯片相当于什么水平？
- 这张显卡比我的旧卡强多少？
- 买笔记本时，这块 CPU / GPU 处于哪个梯队？

## 包含五张榜单

| 类别 | 说明 |
| --- | --- |
| 📱 手机 SoC 天梯图 | 智能手机 / 平板处理器 |
| 🖥️ 台式机 CPU 天梯图 | 桌面处理器 |
| 💻 笔记本 CPU 天梯图 | 移动处理器（含 Apple Silicon） |
| 🎮 台式机显卡 GPU 天梯图 | 桌面独立显卡 |
| 🏷️ 笔记本显卡 GPU 天梯图 | 移动独显与核显 |

每张榜单收录 80 款硬件（共 400 条），覆盖 2026 年 10 月最新的旗舰（如骁龙 8 Elite Gen 6、Zen 6 锐龙、RTX 50 系列）一路到多年前的经典老款与入门款。

## 主要功能

- **类别切换**：五张榜单一键切换
- **页面内搜索**：支持型号与别名（如 `5090`、`天玑`、`9800X3D`、`M4`），关键词实时高亮，快捷键 `/` 聚焦、`Esc` 清空
- **梯队分级**：每款硬件按相对性能分为 S（旗舰）/ A（高端）/ B（主流）/ C（中端）/ D（入门）五档，徽章与彩条同色标注
- **品牌标识**：NVIDIA、AMD、Intel、Apple、高通、联发科、麒麟等品牌以专属色点区分

## 数据说明

分数为综合公开跑分（Cinebench / Geekbench / 3DMark / 安兔兔等）归一化后的**相对性能指数**（同类别榜首 = 100），仅供横向参考，不代表绝对性能；带 X3D / 3D 缓存的型号在部分游戏场景实际表现更高。数据整理自公开评测，截至 **2026 年 10 月**，若有出入以厂商官方规格为准。
